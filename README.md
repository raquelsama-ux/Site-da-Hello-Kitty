# 🎀 Site da Hello Kitty

Um site temático inspirado no universo da Hello Kitty e da Sanrio, desenvolvido utilizando **HTML5, CSS3 e JavaScript** como projeto de estudos em desenvolvimento web.

## 🌐 Demonstração

Acesse o projeto publicado:

👉 https://raquelsama-ux.github.io/Site-da-Hello-Kitty/

---

## 📸 Funcionalidades

- 🩷 Layout inspirado no site oficial da Sanrio
- 🎠 Banner em formato de carrossel com transição automática
- 📱 Layout responsivo para desktop e dispositivos móveis
- ✨ Animações durante a rolagem da página
- 📖 Página apresentando a história da Hello Kitty
- 🌸 Seção sobre o universo da Sanrio
- 📬 Formulário de contato
- 🎮 Mini game "Jogo dos Laços"
- 🏆 Sistema de ranking utilizando Local Storage
- 👥 Modo multiplayer no jogo
- 📱 Menu responsivo para telas menores

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Flexbox
- CSS Grid
- Local Storage
- Intersection Observer API

## 🎮 Mini Game

O projeto inclui um jogo chamado **Jogo dos Laços**, onde o jogador deve coletar o maior número possível de laços antes que o tempo termine.

### Recursos

- Dois níveis de dificuldade
- Objetos especiais
- Obstáculos
- Sistema de pontuação
- Ranking permanente usando Local Storage
- Modo multiplayer entre Hello Kitty e Kuromi

O site foi desenvolvido para funcionar em diferentes resoluções, adaptando automaticamente elementos como:

- Menu

- Seções de conteúdo
- Formulário
- Rodapé

---

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/RaquelSama-UX/Site-da-Hello-Kitty.git
```

Abra o arquivo `index.html` em qualquer navegador moderno.

Ou utilize uma extensão como **Live Server** no Visual Studio Code para uma melhor experiência de desenvolvimento.
